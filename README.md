# AI Mystery Room

An interactive, AI-powered mystery investigation web application where users solve logically consistent fictional crimes generated by Google Gemini.

Built with **Spec-Driven Development (SDD)** based on [spec.md](./spec.md).

---

## Key Features

- **Multi-Stage AI Synthesis**: Uses Google Gemini (`@google/genai`) with structured JSON schema outputs to construct coherent crimes, suspect dossiers, alibis, and discoverable contradictions.
- **Zero-Leak Cheat Prevention**: Culprit IDs, motives, and private truth records are physically isolated in a separate database collection (`MysterySolutionModel`). Public DTOs guarantee zero solution leaks.
- **Deterministic Consistency Validator**: Validates that every case has at least 3 suspects, unique IDs, a chronologically sound timeline, and at least 2 independent decisive clues that expose the culprit.
- **Detective Workspace**:
  - **Evidence Locker**: Sift through simulated WhatsApp chat logs, surveillance CCTV storyboards, witness interrogations, and digital telemetry records.
  - **Persons of Interest Dossier**: Inspect suspect connections, initial statements, known motives, and stated alibis.
  - **Timeline View**: Chronological sequence of verified facts linked to evidence items.
- **Authoritative Scoring & Solution Reveal**: Atomic server-side accusation scoring with duplicate-submission protection. Full post-accusation breakdown reveals decisive clues and explains red herrings.
- **Resilient Fallback Engine**: Cases generate and play completely even without an external image provider or API key using built-in procedural synthesis.

## Getting Started

### Prerequisites

- Node.js 18+ (tested on Node v24)
- npm 9+
- MongoDB (optional for local dev; automated tests run standalone)
- Google Gemini API key (optional; procedural generator activates if key is absent)

### 1. Installation

```bash
npm install
```

### 2. Environment Configuration

Copy `.env.example` to `.env`:

```bash
cp .env.example .env
```

*(Optional)* Set your `GEMINI_API_KEY` in `.env` to enable live Gemini AI mystery generation.

### 3. Running Development Servers

Start both frontend and backend concurrently:

```bash
npm run dev
```

- Frontend: `http://localhost:5173`
- Backend API: `http://localhost:5000`
- Health check: `http://localhost:5000/health`

### 4. Running Automated Tests

```bash
npm run test:server
```

Runs all 24 unit, domain, consistency, and API tests.

### 5. Production Build

```bash
npm run build
```

Compiles both server (`tsc`) and client (`vite build`).
